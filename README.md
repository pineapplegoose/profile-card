💫 Teni’s Profile Card

A fun and minimal profile card web page built with HTML, CSS, and vanilla JavaScript.
This project showcases a clean design, smooth user interaction, and a working Contact Form with input validation — no frameworks, no libraries, just pure code.

✨ Features

🪄 Dynamic Contact Form Validation — Ensures all fields are filled correctly before submitting.

💌 Email Format Check — Validates user email addresses in real-time.

⚠️ Error Feedback — Shows friendly error messages and visual indicators for missing or invalid input.

🧭 Navigation Button — A simple back button to return to the previous page.

🎨 Aesthetic Design — Styled with custom CSS for a clean, modern look.

⚡ Lightweight and Fast — 100% vanilla HTML, CSS, and JS.

🧠 How It Works

When a user fills out the contact form and clicks Submit:

JavaScript checks that all required fields — Full Name, Email, Subject, and Message — are filled.

If any field is invalid, an inline error message appears under that field.

Once all inputs are valid, the form submits successfully, and an alert confirms submission.
